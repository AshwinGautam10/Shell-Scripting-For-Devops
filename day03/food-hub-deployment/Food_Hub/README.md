# 🍔 Food Hub - Food Ordering Website

A responsive **Food Ordering Website** built using **HTML5, CSS3, and JavaScript**.  
It allows users to browse menus, explore dishes, read food blogs, and place online orders with an attractive UI.

---

## ✨ Features

- 🏠 **Home Page** – Welcomes users with a modern landing section.  
- 🍕 **Order Page** – Browse pizzas & dishes with prices, discounts, and "Add to Cart".  
- 📰 **Blogs Page** – Food stories and blogs with images.  
- 🛒 **Cart Page** – Manage added items (to be integrated).  
- 🔑 **Login Button** – For future authentication functionality.  
- 📱 **Responsive Design** – Works on desktop and mobile.

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & Layout  
- **JavaScript (optional for interactivity)**
